1. Какие области видимости существуют

2. Как изменить вложенную и глобальную перемененые (nonlocal, global)
3. Какой порядок разрешения методов в Python (MRO)
Типы наследования:
- Одиночное - класс наследуется от одного класса
- Многоуровневое - класс наследуется от класса, который уже наследуется от другого класса
- Множественное - класс наследуется от нескольких классов
4. Что делает функция super()
Используется для вызова метода родительского класса внутри дочернего. 
Это позволяет расширять или переопределять унаследованные методы, 
сохраняя при этом функциональность родительского класса. 
Особенно полезно использовать метод super() при множественном наследованиии и 
при определении атрибутов в конструкторе класса init
5. Что делает декоратор @property и для чего он нужен
Это декоратор, который позволяет контролировать доступ к атрибутам класса, 
добавляя определенную логику без изменения привычного синтаксиса работы с атрибутами.

# БД 

1. Что такое нормализация? Соответствие какой нормальной форме считается стандартом?
Первая нормальна форма :
- исключить повторения в отдельных таблицах
- создать отдельную таблицу для каждого набора связных данных
- определить каждый набор связных данных с первичным ключом
Вторая нормальная форма:
- создать отдельные таблицы для наборов значений, которые применяются к нескольким записям
- связать эти таблицы внешним ключом
Третья нормальная форма:
- исключить поля, которые не зависят от ключа

2. Что такое транзакция?
Это группа операций с БД, которые выполняются как одно целое. 
Транзакция может быть выполнена либо целиком и успешно, 
либо не выполнена вообще - в этом случае ни одна из операций 
транзакции не должна быть выполнена и никакие изменения в БД не должны быть внесены.
3. Какие требования включает ACID?
- Атомарность: гарантирует, что операции в рамках транзакции будут выполнены все либо не будут 
выполнены вообще. Транзакция не может быть вополнена частично
- Согласованность: транзакция переводит БД из одного согласованного состояния в другое, без сохранения каких-либо несогласованных промежуточных состоянийю Каждая успешная транзакция должна фиксировать только допустимые состояния
- Изолированность: транзакция не должна оказывать влияние на результат других транзакций, выполняемых параллельно
- Надежность: Изменения, которые успешно завершенная транзакция внесла в БД, должны сохраниться даже в случае сбоя.
